# Streamlit Sample Practices

This repository contains various sample **Streamlit applications** built for learning and practice purposes.

These mini-projects demonstrate different functionalities such as calculations, database handling, authentication, and UI design using Streamlit.

---

##  Applications Included

### 1️⃣ Temperature Converter
- Convert temperature between Celsius, Fahrenheit, and Kelvin.

### 2️⃣ Mood-Based Alarm
- Alarm system that plays music based on the selected mood.

### 3️⃣ Login System
- Simple authentication interface using username and password validation.

### 4️⃣ Expense Tracker
- Track daily expenses and manage spending records.

### 5️⃣ Student Management System (SQLite3)
- Add, view, update, and delete student records.
- Uses SQLite3 as the database.

### 6️⃣ Currency Converter
- Convert between different currencies.
- Useful for tracking currency values.

### 7️⃣ BMI Calculator
- Calculate Body Mass Index based on height and weight.
- Displays health category based on BMI value.

### 8️⃣ Simple Calculator
- Perform basic arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division

---

## Technologies Used

- Python
- Streamlit
- SQLite3
